개인정보 처리방침

최종 수정일: 2026-11-21

1. 수집 목적

이 사이트는 수업용 게임 두 가지를 제공합니다. 프롬프트 아레나는 「인공지능 기초」 수업에서 프롬프트 설계를, 디버그 아레나는 정보 프로그래밍 수업에서 파이썬 디버깅을 연습하는 게임입니다. 회원가입이나 로그인 없이 이용하며, 학생을 알아볼 수 있는 개인정보는 수집하지 않습니다.

2. 수집 항목

  • 이름, 학번, 이메일, 연락처 등 식별정보는 받지 않습니다.
  • 로그인 기능이 없어 비밀번호나 계정 정보도 수집·저장하지 않습니다.
  • 프롬프트 아레나에서 입력한 프롬프트와 AI 출력은 답변 생성과 채점에만 쓰이고 게임 서버에 저장하지 않습니다.
  • 디버그 아레나에서 고친 코드는 학생의 브라우저 안에서만 실행되며 어디로도 전송되지 않습니다.

3. 보유 및 이용 기간

  • 보관하는 개인정보가 없습니다.
  • 점수와 진행 상황은 지금 열려 있는 화면(브라우저 메모리)에만 있고, 새로고침하거나 창을 닫으면 사라집니다.
  • 호출 횟수 제한용 세션 기록(무작위 번호와 시도 횟수)은 서버 메모리에 잠시 있다가 서버가 내려가면 사라집니다.

4. 외부 API 사용 안내

본 서비스는 다음 외부 API를 사용합니다. 디버그 아레나는 게임 중 어떤 API도 호출하지 않습니다(문제은행은 Solar로 미리 만들어 검증한 뒤 정적 파일로 넣어 두었습니다).

  • Upstage Solar API — AI 답변 생성과 채점을 위해 학생이 입력한 프롬프트, 미션 자료, AI 출력을 전송합니다. 요청은 게임 중계 서버를 거쳐 보내므로 학생의 IP 주소나 브라우저 정보는 Upstage에 전달되지 않습니다. 전송된 내용의 처리는 Upstage의 정책을 따릅니다.

데이터는 서비스 운영을 위한 기술적 처리 목적으로만 사용하며, 외부 API 제공사에 학생 식별정보가 전달되지 않도록 설계되었습니다. 다만 학생이 프롬프트에 직접 쓴 내용은 그대로 전송되므로 자신이나 친구의 이름·전화번호·주소 등 개인정보를 프롬프트에 쓰지 마세요.

5. 브라우저에 남는 정보

쿠키, 로컬 저장소(localStorage), 세션 저장소(sessionStorage)를 쓰지 않습니다. 화면 글꼴(Pretendard)과 디버그 아레나의 브라우저용 파이썬(Pyodide)은 jsDelivr CDN에서 불러오며, 이때 파일 요청에 필요한 접속 정보가 jsDelivr에 전달됩니다.

6. 안전성 확보 조치

  • HTTPS 전 구간 암호화 (HSTS 적용)
  • CSP, X-Content-Type-Options, Referrer-Policy 등 보안 헤더 적용 (수업 갤러리 등 다른 사이트 안에 표시할 수 있도록 화면 삽입은 허용)
  • AI API 키는 서버 환경변수에만 두고 브라우저 코드·응답·로그에 노출하지 않음
  • 호출 제한: 프롬프트 1000자, 미션당 3회, 게임당 15회 (서명된 세션 토큰으로 검증)
  • 수업과 관련 없는 요청(폭력·선정·개인정보 수집 등)은 AI가 답하지 않도록 시스템 지시로 차단
  • 서버 로그에는 오류 상태 코드만 남기고 프롬프트·출력 내용은 기록하지 않음
  • 디버그 아레나의 학생 코드는 브라우저의 격리된 작업 공간(Web Worker)에서 실행하고, 4초 안에 끝나지 않으면 강제 종료

7. 처리 위탁

수집하는 개인정보가 없어 개인정보 처리 위탁은 없습니다. 서비스 운영에는 아래 업체를 이용합니다.

  • Vercel — 웹사이트와 중계 서버 호스팅. 접속 기록(IP 주소, 접속 시각 등)이 Vercel 정책에 따라 남을 수 있습니다.
  • Upstage — AI 답변 생성과 채점 (4항 참고)
